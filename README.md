GIT HUB TEST

STEP 1: LEADER SETUP
- LEADER WILL CLONE THE REPO FROM GITHUB.
- AFTER CLONING THE REPO USE THIS COMMAND ONCE `rm -rf .git` TO REMOVE PREVIOUS GIT.
- LEADER WILL CHANGE THE `team_code` AND RENAME THE FOLDER WITH THEIR TEAM NAME
- ALSO LEADER WILL UPDATE THE .gitkeep FILE IN TEAMINFO WITH THEIR TEAM MEMBERS NAME AND LEADER 
- LEADER WILL PUSH THIS INITIAL TEAM FOLDER TO GITHUB (MAIN BRANCH).

STEP 2: CREATE YOUR OWN BRANCH NAMED `
- ALL MEMBERS WILL CLONE THE REPO.
- EACH MEMBER CREATES THEIR OWN BRANCH NAMED LIKE `adi-html-home` OR `adi-css-home` OR `adi-js-home`:
  • MEMBER 1: HTML FILE
  • MEMBER 2: CSS FILE
  • MEMBER 3: JS FILE

STEP 3: WORK ON YOUR ASSIGNED PAGE
- OPEN THE `Solution_code` FOLDER.
- FIND YOUR ASSIGNED PAGE FILE.
- COPY THE CODE BLOCKS ONE BY ONE INTO YOUR FILE UNDER 

STEP 4: MAKE THREE PROGRESSIVE COMMITS
  HOME PAGE
- COMMIT 1 MESSAGE: "html-home commit 1"
- COMMIT 2 MESSAGE: "html-home commit 2"
- COMMIT 3 MESSAGE: "html-home commit 3"

  css PAGE
- COMMIT 1 MESSAGE: "css-about commit 1"
- COMMIT 2 MESSAGE: "css-about commit 2"
- COMMIT 3 MESSAGE: "css-about commit 3"

  js PAGE
- COMMIT 1 MESSAGE: "js-contact commit 1"
- COMMIT 2 MESSAGE: "js-contact commit 2"
- COMMIT 3 MESSAGE: "js-contact commit 3"
  

STEP 5: PUSH CODE & CREATE PULL REQUEST
- PUSH YOUR BRANCH CODE TO GITHUB.
- GO TO GITHUB AND CREATE A PULL REQUEST (PR) TO MERGE YOUR BRANCH INTO `main`.

STEP 6: MERGE PULL REQUESTS
- REVIEW AND APPROVE THE PULL REQUESTS ON GITHUB TO MERGE EVERYONE'S CODE INTO `main`.

STEP 7: PULL FINAL CODE & TEST WEBSITE
- EVERYONE RUNS THE ENTIRE CODE ON THEIR LAPTOP.
- OPEN `team_code/index.html` IN YOUR BROWSER TO TEST THE FULL WEBSITE!
